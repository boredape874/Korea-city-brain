# Korea City Brain

김해·장유를 대상으로 만든 한국형 시티 브레인의 첫 실행 모델입니다. 도시 데이터를 한 화면에서 관측하고 혼잡 구간을 분류한 뒤 담당자가 대응을 검토하는 흐름을 보여줍니다.

## 웹 접속 · GitHub Pages

배포가 성공하면 https://boredape874.github.io/Korea-city-brain/ 에서 이용할 수 있습니다. main 브랜치에 변경을 올리면 GitHub Actions가 테스트 후 web 디렉터리를 자동 배포합니다. 공개 웹에서는 실제 지도와 합성 교통 시나리오 분석, GeoJSON 입력, 결과 다운로드를 사용할 수 있습니다. Actions가 ITS를 호출하고 결과 스냅샷을 Pages에 배포합니다. 브라우저에서 인증키를 다루지 않습니다.

첫 배포에서 Pages 자동 활성화가 권한 때문에 실패하면 저장소 Settings → Pages → Source를 GitHub Actions로 선택하고 Actions에서 배포 워크플로를 다시 실행하세요. API 키를 GitHub Pages 코드나 브라우저 입력에 넣지 마세요.

## 실행

Python 3.10 이상 설치 후 저장소를 내려받으세요. 추가 Python 패키지는 필요 없습니다.

```bash
python server.py
```

브라우저에서 http://127.0.0.1:8080 접속. Windows에서는 `start.cmd`를 실행할 수도 있습니다. 지도에는 인터넷 연결이 필요합니다.

## 지금 구현된 기능

- 실제 OpenStreetMap 지도와 확대·이동
- 김해·장유 생활권의 명시적인 합성 교통 시나리오
- 속도 기반 혼잡 분류, 우선 확인 대상, JSON 분석 결과 내려받기
- 서버에서 ITS 교통소통정보 API 호출, 60초 캐시, 인증키를 프론트엔드에 노출하지 않음
- LINK_ID로 표준노드링크 GeoJSON과 교통 속도를 결합하여 실측 도로 선형 색상 표시
- 실패 시 모의 데이터를 실시간처럼 표시하지 않고 데이터 없음으로 처리

## 실시간 데이터 연결

ITS 국가교통정보센터에서 교통소통정보 API 인증키를 발급받은 뒤 서버 환경변수 `ITS_API_KEY`에 설정하고 재시작하세요. 키를 저장소에 커밋하지 마세요.

PowerShell:
```powershell
$env:ITS_API_KEY="발급받은키"
py -3 server.py
```

Linux / macOS:
```bash
export ITS_API_KEY='발급받은키'
python3 server.py
```

화면에서 `ITS 실시간 조회` 선택. 김해 일대 경위도 범위로 조회합니다. API 어댑터는 공식 소개 페이지의 요청·응답 구조를 기준으로 작성했습니다. **실제 인증키가 없어 실서비스 호출 성공은 검증하지 않았습니다.** 승인받은 서비스의 최신 엔드포인트·응답 형식과 지역 커버리지를 확인해야 합니다. 데이터가 없는 지역은 관측 부재이며 원활함을 뜻하지 않습니다.

공식 자료:
- https://www.its.go.kr/opendata/intro
- https://www.its.go.kr/file/opendata/openapi_manual.pdf
- https://www.data.go.kr/data/15040463/openapi.do

## 도로를 지도에 표시하려면

ITS 속도 응답의 linkId만으로 좌표를 임의 생성하지 않습니다. 공식 표준노드링크 도로 자료를 WGS84(EPSG:4326) GeoJSON으로 변환하여 화면의 파일 입력으로 연결하세요. properties.LINK_ID 또는 properties.linkId 값은 문자열이어야 하며, geometry는 LineString/MultiLineString입니다. 투영 좌표를 경위도로 변환하지 않고 넣으면 표시가 틀립니다. 표준노드링크 배포 버전과 관측 링크의 일치 여부도 확인해야 합니다.

```json
{"type":"FeatureCollection","features":[{"type":"Feature","properties":{"LINK_ID":"실제링크ID"},"geometry":{"type":"LineString","coordinates":[[128.81,35.20],[128.82,35.21]]}}]}
```

위 좌표는 형식 예시이며 실제 도로 자료가 아닙니다. 모의 모드의 점 역시 생활권 대표 위치로 실제 센서·도로 위치가 아닙니다.

## 분석의 의미와 한계

20km/h 미만 혼잡, 40km/h 미만 서행은 데모용 규칙입니다. 도로 등급·제한속도·시간대별 기준으로 보정해야 합니다. 평균 속도는 구간 단순 평균이며 도시 전체 교통 성과가 아닙니다. fetchedAt은 수집 시각, createdDate는 제공기관 관측 시각입니다. 관측 시각을 KST로 해석해 10분 이상 노후, 미래 시각 이상, 미확인 시각을 구분합니다. 10분은 데모 품질 기준이며 기관별 갱신주기에 맞춰 조정해야 합니다.

현재 모델은 규칙 기반 의사결정 지원 프로토타입입니다. 학습 AI, 교통 예측, 최적 신호 제어, CCTV 분석, 긴급차량 우선신호, 실제 행정기관 연계는 아직 구현하지 않았습니다. 대응 제안은 담당자 검토용이며 도로 제어 명령을 발행하지 않습니다. 서버는 로컬 주소에만 바인딩합니다.

## 다음 개발 단계

1. 공식 도로 형상 및 관측 시각 검증 → 결측·노후 데이터 구분
2. 사고·공사·날씨·버스 정보 수집 → 관측 기반 원인 후보 표시
3. 과거 데이터를 축적하여 혼잡 예측 → 단순 지속 예측과 성능 비교
4. 시뮬레이션에서 대응 효과 검증 → 실제 효과로 오인하지 않도록 분리
5. 담당자 승인·감사 이력·중단 및 복구 절차를 갖춘 기관 연계

## 검증

```bash
python -m unittest -v
```

Python 어댑터·분류 테스트 및 로컬 HTTP 응답 점검을 수행했습니다. 실제 ITS 키 호출과 브라우저 지도 렌더링은 검증되지 않았습니다. Leaflet 1.9.4와 OSM 타일은 외부 네트워크가 필요합니다. 운영 확대 전 지도 제공 정책과 데이터 이용 조건을 확인하세요.


## Actions 실측 수집 설정

Settings → Secrets and variables → Actions → New repository secret에서 `ITS_API_KEY`를 등록하세요. Actions 워크플로를 실행하면 ITS 조회 결과가 Pages에 배포됩니다. 매시 7/22/37/52분(15분 간격) 수집을 예약합니다. GitHub 실행은 지연되거나 누락될 수 있어 실시간 관제 주기를 보장하지 않습니다. 수집 시각이 20분 이상 지난 결과는 최신으로 표시하지 않습니다. 제공기관 관측시각의 노후 여부도 표에 표시합니다.

키가 없거나 요청이 실패하면 데이터 없음으로 표시합니다. 실제 키 호출은 미검증입니다. 지도 도로 선형은 표준노드링크 GeoJSON으로 결합합니다. 실측 JSON은 공개 Pages에 배포되므로 데이터 재공개 조건을 확인하세요.

## 모의실험 v2 · 연결망과 유한 저장공간

독립 대기행렬을 연결망 모델로 교체했습니다. D(진입) → A(병목)/B(우회) → C(합류) → 출구이며, 외부 유입은 D/B/C에 발생합니다. 10초 단위로 자유통행 이동시간, 신호 게이트, 하류 여유 공간, 합류 유입 배분, 진입 대기열을 계산합니다. 이동 중인 차량도 저장공간에 포함합니다. 하류가 차면 상류 유출이 제한되고 진입하지 못한 수요도 망 밖 대기열에 남습니다. 차량은 연속 유량 근사이며 차량별 운전·차로변경을 구현한 미시 시뮬레이터가 아닙니다.

90초 주기에서 A 녹색 40초, C 녹색 55초를 가정합니다. 사고는 A 처리용량을 55% 줄이고 대응은 A 녹색 55초 및 D의 분기 A/B=60/40을 적용합니다(기본 80/20). 대응 녹색을 늘릴 때 다른 접근로에 줄어드는 녹색의 비용은 현재 경계 밖이며 평가하지 않습니다. 따라서 결과는 교차로 전체 최적화나 실제 개선율을 증명하지 않습니다. 저장공간·처리용량·수요·좌표 모두 미보정 가정이며 실제 도로 연결망으로 오인하면 안 됩니다.

평시·출퇴근·사고·대응 프리셋, 1/5/15배속, 수요 조절, 사고/대응 토글, 초기화 및 JSON 내보내기를 제공합니다. 무대응과 대응은 동일한 난수 수요를 받습니다. seed 42는 재현용이며 5개 seed 비교는 120분 고정 입력에서 민감도를 보여줍니다. 표시 범위는 표본 범위이고 신뢰구간이 아닙니다. 대기는 각 10초 구간 끝 차량 수를 합산한 차량·분입니다. 속도는 자유통행시간과 추정 대기를 합한 환산 속도이며 완료 차량의 실측 평균속도가 아닙니다.

`node test_simulation.cjs`는 각 링크 및 전체 망의 차량 보존, 저장 한도, 진입 대기 유지, 동일 수요, 무대응 동일성, seed 재현, 시간 제한, 반복 비교를 검증합니다. `node test_app.cjs`는 버튼 및 데이터 표시 연결을 검증합니다. 지도·레이아웃의 실제 브라우저 QA를 대체하지는 않습니다.
